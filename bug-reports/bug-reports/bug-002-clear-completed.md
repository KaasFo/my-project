# BUG-001. Задача из пробелов добавляется в список

**Связанный тест-кейс:** TC-011
**Приоритет:** Средний

## Шаги воспроизведения
1. Ввести несколько пробелов в поле ввода
2. Нажать «Добавить»

## Ожидаемый результат
Кнопка «Очистить выполненные» не работает

## Фактический результат
Задача с пустым текстом появляется в списке.
